| 分类 | 符号/元字符 | 含义与说明 | 匹配示例 |
| --- | --- | --- | --- |
| **基础常数** | `abc` | 匹配纯文本字符串 "abc" | `abc` $\rightarrow$ **abc** |
|  | `.` | 匹配**除换行符以外**的任意单个字符 | `a.c` $\rightarrow$ **abc**, **a2c**, **a-c** |
| **字符集合** | `[abc]` | 匹配括号内的**任意一个**字符（字符集） | `[st]ar` $\rightarrow$ **sar**, **tar** |
|  | `[^abc]` | 匹配**不在**括号内的任意一个字符（取反） | `[^st]ar` $\rightarrow$ **bar** (不匹配 sar) |
|  | `[a-z]` | 匹配指定**范围**内的任意一个小写字母 | `[a-c]at` $\rightarrow$ **aat**, **bat**, **cat** |
|  | `[0-9]` | 匹配任意一个数字 | `id-[0-9]` $\rightarrow$ **id-5** |
| **预定义字符集**(简写形式) | `\d` | 匹配任意一个数字，等价于 `[0-9]` | `page\d` $\rightarrow$ **page1** |
|  | `\D` | 匹配任意一个**非**数字，等价于 `[^0-9]` | `\D\D` $\rightarrow$ **AB**, **ab** |
|  | `\w` | 匹配任意一个字母、数字或下划线（单词字符） | `\w` $\rightarrow$ **a**, **Z**, **3**, **_** |
|  | `\W` | 匹配任意一个**非**单词字符（如空格、标点） | `\W` $\rightarrow$ **&**, **!**, **空格** |
|  | `\s` | 匹配任意一个空白字符（空格、制表符、换行符） | `a\sb` $\rightarrow$ **a b** |
| **边界匹配** | `\^` | 匹配字符串的**开头**位置 | `^SQL` $\rightarrow$ **SQL** server (my SQL 不匹配) |
|  | `$` | 匹配字符串的**结尾**位置 | `sql$` $\rightarrow$ learn **sql** (sql developer 不匹配) |
|  | `\b` | 匹配一个单词的边界（即字与空格/标点间的位置） | `\bcat\b` $\rightarrow$ a **cat** here (catty 不匹配) |
| **量词** | `*` | 匹配前面的字符 **0 次或多次**（最多可到无穷次） | `lo*ve` $\rightarrow$ **lve**, **love**, **looove** |
|  | `+` | 匹配前面的字符 **1 次或多次**（至少出现 1 次） | `lo+ve` $\rightarrow$ **love**, **looove** (lve 不匹配) |
|  | `?` | 匹配前面的字符 **0 次或 1 次**（即可选件） | `apples?` $\rightarrow$ **apple**, **apples** |
|  | `{n}` | 匹配前面的字符**恰好 n 次** | `\d{4}` $\rightarrow$ **2026** |
|  | `{n,}` | 匹配前面的字符**至少 n 次** | `\d{3,}` $\rightarrow$ **123**, **12345** |
|  | `{n,m}` | 匹配前面的字符 **n 到 m 次** | `a{1,3}` $\rightarrow$ **a**, **aa**, **aaa** |
| **逻辑与分组** | `\|` | 逻辑“或”（OR），匹配左边或右边的表达式 | `cat|dog` $$\rightarro$ **cat**, **dog** |
|  | `()` | 捕获分组，将多个字符组合成一个单元（整体量词） | `(ab)+` $\rightarrow$ **ab**, **abab**, **ababab** |
| **转义字符** | `\` | 特殊字符转义。将有特殊含义的符号变为普通文本 | `\.` $\rightarrow$ 匹配纯文本的句点 **.** |

1. 在两次后加入 `?` 可以转换为惰性模式

2. 在大部分 SQL 环境中，由于数据库本身也使用单引号和反斜杠做转义，写 `\d` 数据库可能会报错。通常需要写成 **`\\d`**（双反斜杠）转义两次。
